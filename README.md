# AI Product Showcase

Static portfolio website for GitHub Pages.

## Publish

1. Create a public GitHub repository, for example `ai-product-showcase`.
2. Upload **the contents of this `ai-showcase` folder** to the repository root (so `index.html` is at the root).
3. In GitHub repository Settings → Pages, choose **Deploy from a branch**, `main`, `/ (root)`, and save.
4. Wait for the Pages URL to appear in Settings → Pages.
